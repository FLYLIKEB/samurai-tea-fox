# 아트 에셋 브라우저 파이프라인

아트 에셋 DB와 로컬 에셋 파일을 비교하거나, `tools/asset_browser/` 같은 보조 도구를 만들고 사용할 때 적용한다.

## 정본

- 실제 제작해야 할 캐릭터, 타일, 오브젝트, 던전, UI, 이펙트 목록은 `🎨 아트 에셋` DB가 정본이다.
- 시각 원칙은 `09. 아트디렉션·맵·UI` 문서를 따른다.
- 로컬 파일은 정본이 아니라 현재 구현/제작 상태의 증거다.

## 로컬 경로

- 캐릭터와 오브젝트: `assets/sprites/`
- 타일: `assets/tiles/`
- UI: `assets/ui/`
- 오디오: `assets/audio/`
- 아트 관련 도구: `tools/asset_browser/`

## 작업 규칙

- 에셋 제작 목록을 Markdown이나 코드에 중복해서 늘리지 않는다.
- 파일명은 안정적인 asset ID와 용도를 드러내게 한다.
- DB의 제작 상태, 파일 경로, 규격과 로컬 파일 상태를 분리해서 보고한다.
- 테스트용 임시 에셋은 실제 제작 완료 에셋처럼 취급하지 않는다.
- bitmap 파일 자체를 수정해야 하면 이미지 생성/편집용 도구를 사용하고, 스킬 문서에는 지침만 둔다.

## 검증

- asset browser가 있다면 현재 파일 트리와 DB 매핑을 깨지 않는지 확인한다.
- 새 에셋 경로가 Godot 프로젝트 안에서 접근 가능한지 확인한다.
- UI/HUD 에셋은 `HP / 기운 / 心` 3자원 원칙을 깨지 않는지 확인한다.
