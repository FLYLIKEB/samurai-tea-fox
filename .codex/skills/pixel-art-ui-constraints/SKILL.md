# 픽셀아트와 모바일 UI 규칙

아트, 맵, 타일, UI, HUD, 에셋 요구사항을 만들거나 구현할 때 사용한다. 시각 원칙은 `09. 아트디렉션·맵·UI`가 소유하고, 실제 제작 목록과 상태는 `🎨 아트 에셋` DB가 정본이다.

## 그래픽 원칙

- 32x32 타일 기준의 저해상도 픽셀아트를 우선한다.
- nearest filtering과 정수 배율을 전제로 한다.
- 과한 음영보다 윤곽선, 형태 구분, 단순한 실루엣을 우선한다.
- 귀여운 여우 캐릭터, 사무라이, 다도 모티브를 유지한다.
- 캐릭터는 큰 귀와 꼬리 실루엣이 먼저 읽혀야 한다.

## 타일과 맵

- 타일은 단품 아이콘이 아니라 연결됐을 때 자연스러운 구성을 고려한다.
- 강, 숲, 산, 광산 같은 지형은 연결 방향과 경계 타일을 고려한다.
- 바이옴별 차이는 팔레트와 최소 형태 차이로 처리하고, 공통 32x32 규칙을 유지한다.
- 실제 제작해야 할 에셋 목록, 방향 수, 프레임 수, 제작 상태, 파일은 `🎨 아트 에셋` DB를 정본으로 사용한다.

## 모바일 UI

- 맵이 화면 중심을 차지하고 HUD는 가장자리에 배치한다.
- 상시 스탯 표시는 `HP / 기운 / 心` 3개로 고정한다.
- 별도 `MP`, `SP`, stamina, hunger, thirst, body temperature, fatigue 게이지를 추가하지 않는다.
- 기본 조작축은 이동, 공격, 회피, 차 사용, 요술 버튼이다.
- 밤/수면 정보는 心과 시간대 아이콘 중심으로 표현하고 UI 복잡도를 늘리지 않는다.
- 모바일에서 드래그 정리를 강요하지 않도록 자동 정렬과 필터를 고려한다.

## 금지

- 아트 에셋 제작 목록을 문서나 코드에 중복해서 늘리지 않는다.
- UI가 게임 로직을 소유하게 만들지 않는다.
- 스탯 HUD 요구사항을 늘려 새로운 상시 자원 게이지를 만들지 않는다.
