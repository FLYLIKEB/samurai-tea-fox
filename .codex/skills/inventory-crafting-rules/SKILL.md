# 인벤토리와 제작 규칙

인벤토리, 아이템, 다구, 장비, 제작법, 제작 시설, 자원 채집을 다룰 때 사용한다.

## 인벤토리

- 슬롯형 인벤토리를 사용한다.
- 무게 시스템은 사용하지 않는다.
- 찻잎, 재료, 소모품은 동일 아이템끼리 스택된다.
- 장비와 다구는 개별 슬롯을 사용한다.
- 기본 슬롯 수는 `⚖️ 밸런스 상수`의 `인벤토리 기본 슬롯` 값을 따른다.
- 모바일에서 드래그 정리를 강요하지 않도록 자동 정렬과 종류별 필터를 고려한다.

## 장비와 다구

- 전투 장비는 `무기 1 / 방어구 1`의 최소 구조로 시작한다.
- 무기 내구도는 사용하지 않는다.
- 다구는 단순 능력치 장비가 아니라 차 운용 방식을 바꾸는 도구로 설계한다.
- 다구와 장비의 개별 수치는 `아이템·다구` DB를 정본으로 사용한다.

## 제작

- 제작은 즉시 완료된다.
- 제작 시설은 맵 배치 또는 플레이어 설치 대상으로 다룰 수 있다.
- 시설 주변에는 최소한의 빈 타일 공간 요구를 둘 수 있다.
- 제작법의 정본은 `제작법` DB다.
- 바이옴 핵심 던전 클리어로 열린 제작법은 현재 런에서만 유지된다.
- 런 종료 시 제작 시설과 제작법 진행은 초기화된다.

## 검증

- 슬롯 수, 스택 한도, 개별 슬롯 아이템 직렬화를 테스트한다.
- 제작 조건과 재료 소비를 테스트한다.
- run save와 meta save 경계에 제작 해금이 잘못 저장되지 않는지 확인한다.
- 콘텐츠 이름 조건문 대신 item ID와 recipe ID를 사용한다.
