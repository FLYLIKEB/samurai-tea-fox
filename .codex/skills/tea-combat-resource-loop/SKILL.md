# 차와 전투 자원 루프

전투, 차 준비와 마시기, 기운, 心, 요술, 회피를 구현하거나 검토할 때 사용한다. 이 프로젝트의 상시 플레이어 자원은 `HP / 기운 / 心`만 사용한다.

## 자원 규칙

- 별도 `MP`, `SP`, stamina, hunger, thirst, body temperature, fatigue 게이지를 추가하지 않는다.
- 기본 공격은 별도 자원을 소비하지 않는다.
- 요술은 기운을 직접 소비한다.
- 기운이 높을수록 검 공격력이 강해진다는 관계를 유지한다.
- 기운 최대치와 공격 배율 공식은 `⚖️ 밸런스 상수`를 정본으로 사용한다.
- 心 최대치, 저하 임계값, 요술 기운 소모 증가율도 `⚖️ 밸런스 상수`를 정본으로 사용한다.

## 차 규칙

- 차 준비는 `찻잎 선택 -> 다구 선택 -> 우리기`의 단순 구조를 우선한다.
- 온도, gram, 초 단위 시간을 플레이어가 직접 입력하는 현실 시뮬레이터로 확장하지 않는다.
- 전투 중 차는 퀵슬롯에서 마시고 짧은 동작 시간을 가진다.
- 차의 핵심 역할은 기운 회복이다.
- 개별 차의 수치와 회복 방식은 `차 도감` DB를 정본으로 사용한다.

## 조작 규칙

- 모바일과 키보드 입력은 같은 command 계층으로 합류한다.
- 회피는 별도 stamina 없이 짧은 쿨타임과 짧은 무적시간으로 다룬다.
- 요술 슬롯 수는 `⚖️ 밸런스 상수`의 `요술 장착 슬롯` 값을 따른다.

## 검증

- HP, 기운, 心의 clamp와 경계값을 테스트한다.
- 요술 사용이 기운을 소비하고 별도 MP를 만들지 않는지 확인한다.
- 차 마시기가 기운 회복으로 연결되는지 테스트한다.
- UI나 입력 어댑터가 전투 규칙을 직접 소유하지 않는지 확인한다.
