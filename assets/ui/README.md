# UI Assets

The reusable UI crops are grouped by purpose:

- `branding/`: title plaque, emblem, and seals
- `panels/`: complete framed HUD and menu widgets
- `controls/`: slots, tabs, buttons, toggles, sliders, and navigation controls
- `icons/atlas/`: inventory, menu, marker, and action icons at source resolution
- `decorators/`: reusable bamboo, divider, minimap, and tooltip ornament crops
- `reference/`: visual QA contact sheets excluded from Godot import

`ui-atlas-crops.json` is the crop manifest and source of truth for coordinates. Raw source atlases remain under the gitignored `assets/source/imagegen/title-branding-20260902/` directory.
